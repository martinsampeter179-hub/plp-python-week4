# PLP Python Week 4: Hands-On Lab - Grades, Eligibility & Smart Decisions

This repository contains the solutions for the Week 4 Python assignment focusing on function definition, arguments, return statements, and default parameter values.

## Files Included

* `welcome.py` - Contains the `welcome()` function that refactors repeated code into a reusable greeting generator.
* `toolbox.py` - Contains three utility functions (`double`, `is_pass`, and `greet`) demonstrating basic arithmetic, boolean comparison returns, and default parameters.

## Reflection Question

The `greet()` function in `toolbox.py` was the trickiest to write because it required handling default parameter syntax (`greeting="Hello"`) alongside proper string formatting with commas and exclamation marks. Understanding how optional arguments fall back to their default value when omitted was an insightful takeaway.
